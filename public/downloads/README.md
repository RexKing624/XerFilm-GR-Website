# Same-site firmware downloads

GR IV / HDF V3.11 (v58) and GR III / HDF V3.11 (R39) are published in ordinary and enhanced variants at the owner’s request. GR IIIx / HDF V3.0 (R31) remains the stable release, with R38 available separately as a V3.11 test build after acknowledgement and password verification. No sample-kit download is included.

The browser reconstructs each model-specific BIN from 16 MiB parts, verifies every part and the complete SHA-256, then saves fwdc248b.bin, fwdc243b.bin or fwdc239b.bin. Do not flash parts individually.

Compatible official bases remain GR IV 1.11, GR IIIx 1.60 and GR III 2.10. Enhanced installation versions are GR IV 1.12.10.7, GR IIIx 1.61 and GR III 2.11.

Release manifests record publication approval separately from physical-camera testing. The existing V1.1 historical source and pinned original firmware backups are unchanged.
